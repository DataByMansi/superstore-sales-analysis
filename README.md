

# 🛒 Superstore Sales Analysis

A complete end-to-end data analysis project using Python, SQL, Excel, and Power BI.

## 📊 Project Overview
Analysis of 4 years of US Superstore retail data (9,994 orders) to uncover sales trends,
profitability drivers, and actionable business insights.

## 🔧 Tools Used
| Tool | Purpose |
|---|---|
| Python (Pandas, Matplotlib, Seaborn) | Data cleaning, EDA, visualizations |
| PostgreSQL / pgAdmin | Business queries, advanced SQL analysis |
| Excel | Summary pivot tables and dashboard |
| Power BI | Interactive executive dashboard |
| Jupyter Notebook | Analysis environment |
| GitHub | Version control and project showcase |

## 🔍 Key Business Questions Answered
1. Which product categories are most profitable?
2. How does discount rate affect profitability?
3. Which states/regions are loss-making?
4. What is the year-over-year sales growth trend?
5. Which customer segments drive the most revenue?

## 📈 Key Findings
- **Technology** is the highest revenue category but **Office Supplies** has the best margin
- Discounts above **40%** consistently result in losses across all categories
- **West region** leads in sales; **Central** has the lowest profit margin
- **Tables and Bookcases** are the top loss-making sub-categories
- Sales grew **XX%** from 2014 to 2017 with consistent Q4 peaks

## 🚀 How to Run
1. Clone this repo: `git clone https://github.com/YOUR_USERNAME/superstore-sales-analysis.git`
2. Install requirements: `pip install pandas matplotlib seaborn sqlalchemy psycopg2-binary`
3. Open notebooks in order: `01_data_cleaning` → `02_eda_analysis` → `03_visualizations`
4. Run SQL scripts in pgAdmin against `superstore_db`
5. Open Power BI file to explore the interactive dashboard
